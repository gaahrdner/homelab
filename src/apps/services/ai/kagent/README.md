# kagent

kagent is a Kubernetes-native AI agent platform (CNCF Sandbox) where agents, model configs, and MCP tool servers are managed declaratively as Kubernetes CRDs.

## What This Deployment Does

- Installs standalone `kagent-crds` (`0.10.6`) and `kagent` (`0.10.6`) from `oci://ghcr.io/kagent-dev/kagent/helm` (pinned to the standalone Kubernetes-native 0.10.x line so it does not require the 8-workload Agent Substrate `ate-system` stack)
- Provisions a dedicated PostgreSQL 17 StatefulSet (`kagent-postgresql`) backed by 1Password
- Wires the default `ModelConfig` (`ds4-plan`) through the in-cluster stateless LiteLLM gateway
- Enables `kagent-tools` and the built-in `k8s-agent` (additional built-in agents like `promql-agent`, `helm-agent`, and `cilium-debug-agent` can be toggled in `application.yaml`)
- Exposes the kagent web UI at `http://kagent.internal`

## Required 1Password Items

In the `kubernetes` vault (`mbn7rk3d5gfgofrv3a2zt2tdoe`):

- `litellm-master-key` (`master-key`)
- `kagent-postgresql` (`postgres-password`, `owner-password`, `ownerConnectionString`) — generated by `mise run generate-ai-1password-items`
