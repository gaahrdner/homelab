# Agent Substrate (`ate-system`)

Agent Substrate (`v1.0.1`) provides sandboxed, suspend/resume gVisor actor execution for `kagent 1.0.x`.

## Prerequisites

1. **Talos Kubernetes 1.36 feature gates**: `src/talos/patches/pod-certificates.yaml` enables `ClusterTrustBundle`, `ClusterTrustBundleProjection`, `PodCertificateRequest`, and `certificates.k8s.io/v1beta1`.
2. **1Password secret**: `substrate-postgresql` in vault `mbn7rk3d5gfgofrv3a2zt2tdoe` (generated by `mise run generate-ai-1password-items`).
3. **Internal CA & JWT pool Secrets**: run `scripts/bootstrap-substrate-cas.sh` once per cluster to generate the self-signed signing pools in `ate-system`.

## Components

- `substrate-crds`: Agent Substrate CRDs (`WorkerPool`, `ActorTemplate`, `SandboxConfig`, etc.)
- `substrate-podcert`: `podcertificate-controller` issuing `servicedns.podcert.ate.dev/identity` and `podidentity.podcert.ate.dev/identity`
- `substrate`: `ate-api-server`, `ate-controller`, `ate-idp-server`, `atelet` DaemonSet, `atenet-router`, `atenet-egress`, `k8s-credential-provider`, `rustfs` (1Gi snapshot store), and dedicated `substrate-postgresql`
